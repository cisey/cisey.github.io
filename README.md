# cisey.github.io

Kişisel ana sayfa. GitHub Pages ile yayınlanır: https://cisey.github.io

Bu depo tek bir `index.html` dosyasından oluşur. Sayfa, Pages'i açık olan projelerimin listesini gösterir.

## Projeler

- **Local Radar** — Google Haritalar verisinden mahalle/ilçe/il bazında "nerede yenir, nereye gidilir" rehberleri üretir.
  - Rehberler ve site: https://cisey.github.io/LocalRadar
  - Rehber çıktıları ve site: https://github.com/cisey/LocalRadar
  - Program (kaynak kod): https://github.com/cisey/local-radar

## Nasıl güncellenir?

1. Bu depoda `index.html` dosyasını aç.
2. Sağ üstteki kalem simgesine tıkla, değişikliği yap.
3. "Commit changes" de. Birkaç dakika içinde site güncellenir.
